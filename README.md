# Yuxuan Pan — Academic Website

A responsive, accessible academic website designed for faculty job applications. The site is static and ready for GitHub Pages.

## Local preview

Open `index.html` directly, or serve the folder with any static web server.

## GitHub Pages

This site is published from the root of the `main` branch with GitHub Pages.

## Editing the website on GitHub

1. Open the repository at `https://github.com/KP0127/yuxuanpan.github.io`.
2. Select the file you want to change. Most visible text is in `index.html`, and colors and layout are in `styles.css`.
3. Select the pencil icon, make the edit, and choose **Commit changes**.
4. GitHub Pages will rebuild the public website automatically, usually within a few minutes.

To replace the portrait or CV, upload a new file using the same filename: `yuxuan-pan.jpg` or `CV_Yuxuan_Pan.pdf`. Keeping the filename unchanged avoids editing the links in `index.html`.

The AEC 624 teaching links point to `vif-lab.html` and `wage_equation_exercise.html`. Edit those files directly to update the class materials.
